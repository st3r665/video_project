# 潮汐视频 · 短视频推荐平台 MVP v0.1

一个可直接运行、可现场演示的短视频推荐平台原型。零第三方依赖，Python 标准库实现，跑通「注册登录 → 上传视频 → 刷视频流 → 行为埋点 → 个性化推荐 → 推荐理由可视化」的完整闭环。

> 这是毕业设计《基于双塔模型与实时特征的多阶段短视频推荐系统》的第一个可运行版本。后续将按设计方案逐步迁移为 Spring Boot（业务后端）+ FastAPI（推荐服务）的双服务正式架构。

---

## 快速开始

环境要求：Python 3.8+（无需安装任何第三方包）。ffmpeg 仅用于首次生成测试视频，若 `media/` 下已有视频则无需安装。

```powershell
# 1. 初始化演示数据（首次运行；会生成 48 条测试视频并重建数据库）
python seed.py

# 2. 启动服务
python server.py

# 3. 浏览器打开
#    http://localhost:8000
```

端口冲突时：`set PORT=8001` 后再次 `python server.py`。

## 推荐演示剧本（答辩演示重点）

1. 用 **demo / demo123** 登录，首页推荐流已经明显偏向「篮球」；
2. 观察每条视频左上角的**推荐理由标签**：⚡ 看你最近在看「篮球」、🎯 匹配你的「美食」兴趣、👤 看过《xxx》的人也再看、🔥 热门视频；
3. 或者**注册一个新账号**（冷启动，先给热门），连续看完/点赞 3 条「美食」视频；
4. 点右上角「↻ 换一批」→ 推荐流立刻向「美食」倾斜，且刚看过的视频不再出现；
5. 点击「＋ 上传」发布一条自己的视频（mp4/webm/mov），体验完整创作流程。

## 功能清单

- 用户注册 / 登录 / 退出（PBKDF2 密码哈希 + Token 鉴权）
- 视频上传（multipart，最大 200MB）、本地存储、流式播放（支持 Range 断点续传）
- 视频流（TikTok 式竖屏滚动，IntersectionObserver 自动播放/暂停、静音切换）
- 行为埋点：开始播放（view）、观看进度心跳（progress）、播完（finish）、点赞/取消（like/unlike）
- 混合推荐引擎 + 推荐理由可视化 + 已看视频去重

## 推荐引擎说明

三路打分通道，加权融合（`recommender.py`）：

| 通道 | 权重 | 说明 |
|------|------|------|
| 热门 hot | 0.20 | 播放/点赞加权 + 时间衰减 |
| 兴趣 content | 0.50 | 分类/标签画像 + 最近 5 次观看的实时加权（×2） |
| 协同 itemcf | 0.30 | 基于物品的协同过滤（共现余弦相似度 + 行为近因） |

**实时兴趣 boost**：最近浏览过的分类，候选视频总分再 ×1.7，保证「连续刷同类视频后，换一批立刻倾斜」的可感知效果——这就是答辩现场要演示的核心卖点。

每条推荐附带 `debug` 字段（hot/content/itemcf/total 分值），便于写论文时做分数构成分析。

## 目录结构

```
video-platform/
├── server.py        # HTTP 服务：路由、鉴权、上传、媒体流（零依赖）
├── recommender.py   # 混合推荐引擎（热门 + ItemCF + 内容/实时兴趣）
├── seed.py          # 演示数据初始化（ffmpeg 生成测试视频 + 种子账号与行为）
├── static/          # 前端：index/login/upload 三个页面 + 样式与脚本
├── media/           # 视频文件（上传 + 种子视频）
├── data/            # SQLite 数据库（运行时生成）
└── README.md
```

## API 摘要

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/register | 注册，返回 token |
| POST | /api/login | 登录，返回 token |
| POST | /api/logout | 退出 |
| GET | /api/me | 当前用户 |
| GET | /api/feed?count=12 | 推荐流（登录后个性化，否则热门） |
| POST | /api/behavior | 行为埋点 {video_id, event, watch_ratio} |
| POST | /api/upload | 上传视频（multipart：title/category/tags/file） |
| GET | /api/videos/mine | 我上传的视频 |

## 数据表

`users`（用户）、`tokens`（登录态）、`videos`（视频）、`behaviors`（行为日志，推荐的数据来源）。
